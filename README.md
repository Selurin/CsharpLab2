# Задание 1
## Задача 3: Имена

### Текст задачи
Создайте сущность Имя, которая описывается тремя параметрами: Фамилия, Личное имя, Отчество. Имя может быть приведено к строковому виду, включающему традиционное представление всех трех параметров: Фамилия Имя Отчество (например “Иванов Иван Иванович”). Необходимо предусмотреть возможность того, что какой-либо из параметров может быть не задан, и в этом случае он не учитывается при приведении к текстовому виду. 
Необходимо создать следующие имена: 
- Клеопатра 
- Пушкин Александр Сергеевич 
- Маяковский Владимир 
Обратите внимание, что при выводе на экран не заданные параметры никак не участвуют в образовании строки.

### Алгоритм решения
1. Создан класс `Name` с тремя приватными полями типа `string?`: `familia`, `imya`, `otchestvo`.
2. Реализован конструктор с необязательными параметрами (значения по умолчанию `null`), что позволяет создавать объекты с неполным набором данных.
3. Переопределен метод `ToString()`: он последовательно проверяет каждое поле на `!string.IsNullOrEmpty()`. Если поле содержит значение, оно добавляется к результирующей строке. Пробелы добавляются только в том случае, если после текущего элемента следует другой непустой элемент, что гарантирует отсутствие лишних пробелов в начале, конце или середине строки.

### Тестирование
В методе `Main` созданы три объекта `Name`:
- `new Name("", "Клеопатра", "")` → выводится как "Клеопатра"
- `new Name("Пушкин", "Александр", "Сергеевич")` → выводится как "Пушкин Александр Сергеевич"
- `new Name("Маяковский", "Владимир", "")` → выводится как "Маяковский Владимир"

## Задача 4: Время

### Текст задачи
Создайте сущность Время, которое будет описывать текущее время суток в 24-х часовом формате. Время описывается числом секунд, прошедшим с начала суток. Время может быть приведено к текстовой форме следующего формата: “ЧЧ:ММ:СС”. Например, если время задано как 12000, то текстовая форма будет “3:20:00”. Если общее время превышает 24 часа, то отображаться в текстовом виде должно только то время, которое прошло с начала последних суток, например 91800, это не 25:30:00, а 1:30:00. 
Необходимо создать и вывести на экран текстовую форму для следующих вариантов времени: 
• 10 секунд 
• 10000 секунд 
• 100000 секунд 

### Алгоритм решения
1. Создан класс `Time` с приватным полем `int seconds`.
2. Реализован конструктор, принимающий общее количество секунд. Он проверяет значение на неотрицательность (при отрицательном значении выводится ошибка и устанавливается 0).
3. Для корректного отображения времени в пределах суток к значению применяется операция взятия остатка от деления на 86400 (количество секунд в 24 часах): `this.seconds = seconds % 86400`.
4. Метод `ToString()` вычисляет часы (`seconds / 3600`), минуты (`(seconds % 3600) / 60`) и секунды (`seconds % 60`), после чего формирует строку в формате "ЧЧ:ММ:СС".

### Тестирование
Программа успешно обрабатывает входные данные:
- 10 секунд → "0:0:10"
- 10000 секунд → "2:46:40"
- 100000 секунд → "3:46:40" (так как 100000 % 86400 = 13600 секунд, что равно 3 часа 46 минут 40 секунд)

# Задание 2: Сотрудники и отделы

### Текст задачи
Создайте сущность Сотрудник, которая описывается именем (в строковой форме) и отделом, в котором сотрудник работает, причем у каждого отдела есть название и начальник, который также является Сотрудником. Сотрудник может быть приведен к текстовой форме вида: “Имя работает в отделе Название, начальник которого Имя”. В случае если сотрудник является руководителем отдела, то текстовая форма должна быть “Имя начальник отдела Название”. 
Необходимо выполнить следующие задачи: 
1. Создать Сотрудников Петрова, Козлова, Сидорова работающих в отделе IT. 
2. Сделать Козлова начальником IT отдела. 
3. Вывести на экран текстовое представление всех трех Сотрудников (у всех троих должен оказаться один и тот же отдел и начальник). 

### Алгоритм решения
1. Создан класс `Department` со свойствами `Name` (string) и `Manager` (Employee).
2. Создан класс `Employee` со свойствами `Name` (string) и `Department` (Department). Конструктор принимает имя и отдел.
3. В классе `Employee` переопределен метод `ToString()`. Он проверяет условие `this.department.Manager == this`. Если оно истинно, выводится строка "Имя начальник отдела Название". В противном случае формируется строка "Имя работает в отделе Название, начальник которого Имя", с дополнительной проверкой `Manager` на `null` (если начальник не назначен, выводится "не назначен").
4. В `Main` создан отдел "IT", созданы три сотрудника, после чего свойство `it.Manager` установлено на объект `kozlov`.

### Тестирование
При выводе объектов получены следующие строки:
- Петров: "Петров работает в отделе IT, начальник которого Козлов"
- Козлов: "Козлов начальник отдела IT"
- Сидоров: "Сидоров работает в отделе IT, начальник которого Козлов"

# Задание 4: Создаем Время

### Текст задачи
Измените сущность Время из задачи 1.4. Новые требования включают: 
• Время можно создать указав количество секунд с начала суток 
• Время можно создать указав количество часов, минут, секунд текущего времени. 
• Гарантируйте, что операция присвоения в инициализаторах будет использована не более одного раза 
Необходимо создать и вывести на экран текстовую форму для следующих вариантов времени: 
1. 10000 секунд 
2. 2 часа, 3 минуты, 5 секунд 

### Алгоритм решения
1. В класс `Time` добавлен второй конструктор: `Time(int hours, int minutes, int seconds)`.
2. Внутри конструктора выполняется проверка на отрицательные значения. Если данные корректны, вычисляется общее количество секунд: `int totalSeconds = hours * 3600 + minutes * 60 + seconds`.
3. Операция присвоения полю `this.seconds` выполняется ровно один раз в конце блока: `this.seconds = totalSeconds % 86400;`, что удовлетворяет требованию задания.

### Тестирование
Программа корректно обрабатывает оба способа инициализации:
- `new Time(10000)` → "2:46:40"
- `new Time(2, 3, 5)` → "2:3:5"

# Задание 5: Сколько сейчас времени?

### Текст задачи
Измените сущность Время из задачи 4.4. Добавьте ей возможность возвращать следующие сведения: 
• Какой сейчас час (целое число) 
• Сколько минут прошло с начала текущего часа (целое число) 
• Сколько секунд прошло с начала текущей минуты (целое число) 
Необходимо выполнить следующие задачи: 
1. Вывести на экран сколько часов соответствуют времени 34056 
2. Вывести на экран сколько минут соответствуют времени 4532 
3. Вывести на экран сколько секунд соответствуют времени 123

### Алгоритм решения
В класс `Time` добавлены три метода, использующие целочисленное деление и остаток от деления:
1. `GetHours()`: возвращает `this.seconds / 3600`.
2. `GetMinutes()`: возвращает `(this.seconds % 3600) / 60`.
3. `GetSeconds()`: возвращает `this.seconds % 60`.

### Тестирование
Вызовы методов для заданных значений вернули корректные результаты:
- Для 34056 секунд: часов = 9 (34056 / 3600)
- Для 4532 секунд: минут = 15 ((4532 % 3600) / 60 = 932 / 60)
- Для 123 секунд: секунд = 3 (123 % 60)
